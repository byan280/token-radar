Token Radar ranks pre-token protocols by implied value, calibrated from the live-token protocols in the same sealed DefiLlama snapshot, and shows a concrete farm plan for each one. The dashboard is static, works with no network, and covers every protocol on the snapshot's watchlist plus the early pre-token protocols below its floor.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
